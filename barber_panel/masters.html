Здесь можно добавить, отредактировать или убрать мастера — отдельно для мужской команды (барбершоп) и женской команды (салон красоты) — переключайтесь между ними вкладками ниже. Изменения сначала происходят только на этой странице — чтобы они попали и на сайт записи, и во все устройства панели, нажмите «Скачать обновлённый файл» внизу (он сохранит ОБЕ команды сразу) и замените им файл js/data/masters.js в репозитории на GitHub (точно так же, как при первой публикации сайта).

Для нового мастера сначала загрузите его фото в папку img/ на GitHub (например, img/Ivan.png) и впишите точное имя файла в поле «Файл фото» — до этого будет показана заглушка.
