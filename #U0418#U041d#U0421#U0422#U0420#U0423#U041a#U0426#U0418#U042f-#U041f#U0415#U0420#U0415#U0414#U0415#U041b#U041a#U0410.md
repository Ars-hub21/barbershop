# Инструкция: как переделать сайт под другой салон

Этот сайт изначально сделан для барбершопа, но собран так, чтобы его можно
было быстро переоформить под любой другой салон красоты — мужской или
женский. Ниже — что и где менять, по шагам, от простого к сложному.

**Главное правило: файлы `js/core/api.js`, `js/core/config.js` (кроме
времени работы), `js/core/global-cache.js`, `js/core/storage.js` и вся
папка `barber_panel/` — это связь с базой данных и панель администратора.
Их трогать не нужно вообще**, если только вы не хотите поменять сам бэкенд.
Всё, что описано ниже, — только внешний вид и контент страниц.

---

## 1. Самое быстрое: переключить мужскую/женскую версию

Откройте файл **`js/core/site-config.js`** — это единственный файл, который
нужно менять для переключения темы. В самом начале файла:

```js
const SALON_THEME = 'masculine';
```

Замените на:

```js
const SALON_THEME = 'feminine';
```

— и весь сайт (все 7 страниц сразу) перекрасится в бархатную женскую версию:
глубокий баклажан/бордо, розовое золото, мягкие скруглённые углы, буквы без
капса, шрифт с засечками в заголовках. Обратно на мужскую — верните
значение `'masculine'`.

Сами палитры (цвета, шрифты, форма углов) описаны в **`css/theme.css`** —
если хочется подправить оттенок золота, бордо и т.п., значения там,
подписаны по-русски.

### Хотите третью тему (например, унисекс-салон)?
1. В `css/theme.css` скопируйте блок `[data-theme="feminine"] { ... }` целиком,
   переименуйте селектор, например, в `[data-theme="unisex"]`, и поменяйте
   значения переменных.
2. В `js/core/site-config.js` впишите `const SALON_THEME = 'unisex';`.

Готово — редактировать HTML-файлы для этого не нужно.

## 2. Название салона, адрес, слоган

Там же, в **`js/core/site-config.js`**, чуть ниже — объект `BRAND`:

```js
const BRAND = {
  name: 'БАРБЕРШОП',              // подставляется в заголовок вкладки браузера
  addressText: 'Урус-Мартан, ...', // адрес в шапке всех страниц сразу
  tagline: 'Стиль начинается с деталей', // короткий слоган на главной
  showTagline: true,               // false — чтобы слоган не показывался
  roleLabel: 'Барбер'
};
```

Меняете текст здесь — обновляется сразу на всех 7 страницах (адрес в шапке
и заголовок вкладки браузера берутся отсюда автоматически). Название самого
салона и слова вроде "барбер" внутри текста кнопок и заголовков (например,
"Барбершоп — Онлайн-бронирование" целиком, или подписи "Топ-Барбер" на
карточках мастеров) остаются в HTML/JS-файлах ниже — их всё ещё нужно
поправить руками при полном ребрендинге (см. пункт 7 — "Что ещё придётся
поправить руками").

## 3. Услуги и цены

Файл **`js/data/services.js`** — просто массив объектов:

```js
{ id: 1, name: 'Стрижка', description: '...', duration: 60, price: '1400–2000', category: 'main' }
```

Можно менять названия/цены/длительность, добавлять и удалять строки.
`category` — одно из: `main`, `extra`, `complex` (соответствует вкладкам на
странице выбора услуг) — если нужны другие категории, их также надо
прописать в `Services.html` в блоке `.tabs`.

---

## 4. Мастера

Файл **`js/data/masters.js`**:

```js
{ id: 1, name: 'Дени', title: 'Барбер', avatar: 'Deni.png' }
```

Фото мастеров лежат в папке `img/` — просто положите туда новый файл и
укажите его имя в поле `avatar`. Можно добавлять любое количество мастеров.

---

## 5. Галерея работ «До / После»

Это второстепенный блок на главной странице — свёрнут по умолчанию, человек
разворачивает его сам, если хочет посмотреть примеры работ. Внутри каждая
карточка сама переключается между "до" и "после" каждые 3 секунды с
эффектом разрезания фото на полоски; тап/клик по карточке форсирует переход
к "после" сразу.

Файл **`js/data/gallery.js`**:

```js
{ title: 'Классическая стрижка', before: 'img/gallery/before.svg', after: 'img/gallery/after.svg' }
```

Сейчас там стоят схематичные плейсхолдеры (`img/gallery/before.svg` и
`after.svg`) — это не настоящие фото, а заглушки для демонстрации самого
эффекта. Чтобы поставить реальные фотографии:

1. Положите фото "до" и "после" в `img/gallery/` (jpg/png/webp — любой формат).
2. В `gallery.js` впишите пути к ним вместо файлов-плейсхолдеров.
3. Можно добавить сколько угодно карточек — просто скопируйте строку и
   поменяйте `title`/`before`/`after`.

Лучше всего смотрятся фото с соотношением сторон примерно 4:3.

Если галерея вообще не нужна для какого-то салона — удалите блок
`<section class="gallery-widget">…</section>` из `index.html` и строки
`js/data/gallery.js` / `js/pages/gallery-widget.js` из списка `<script>`
внизу той же страницы.

## 6. Кнопка-«ножницы» (индикатор загрузки)

На кнопках "Завершить запись" и "Отправить отзыв" вместо обычного текста
"Загрузка..." теперь ножницы едут по кнопке слева направо и обратно,
наполовину выступая за её край, и состригают "волоски" (мелкие частицы на
холсте). Логика — в **`js/utils/scissors-loader.js`**, полностью
независима от API и данных.

Чтобы применить этот же эффект на любую свою кнопку:

```js
ScissorsLoader.start(myButton, { loadingText: 'Секунду...' });
// ...когда асинхронная операция завершилась...
ScissorsLoader.stop(myButton);                     // вернёт исходный текст кнопки
ScissorsLoader.stop(myButton, { text: 'Готово!' }); // или покажет свой текст
```

Требования: у кнопки не должно быть `overflow: hidden` (в `css/styles.css`
класс `.btn` его и не задаёт — не добавляйте специально, иначе ножницы,
которые должны торчать за края, обрежутся).

Если для салона больше подходит другой инструмент вместо ножниц (например,
расчёска, кисть для макияжа, фен) — SVG-разметка ножниц лежит прямо в
начале `scissors-loader.js` (константа `SCISSORS_SVG`), её можно заменить
на свою, форма и логика движения останутся прежними.

## 7. Что ещё придётся поправить руками при полном ребрендинге

Сайт — статические HTML-страницы без единого шаблонизатора, поэтому часть
текста дублируется в каждом файле и не подхватывается из `site-config.js`
автоматически:

- Слово "БАРБЕРШОП"/"Барбер" внутри `<title>` пишется автоматически (см.
  пункт 2), но если хотите изменить остальной текст заголовка вкладки
  (например, "— Онлайн-бронирование"), правьте `<title>` в каждом из 7
  HTML-файлов вручную.
- Подписи мастеров "Топ-Барбер" в разметке `index.html` (карточки Дени и
  Бауди) — задайте нужное слово прямо там, либо через поле `title` в
  `js/data/masters.js` (`home.js` использует его в приоритете).
- Иконки FontAwesome (ножницы `fa-cut`, расчёска и т.п.) в кнопках и
  заголовках подобраны под барбершоп — для салона другого профиля стоит
  подобрать свои: список есть на сайте fontawesome.com (используется
  версия 6.0.0-beta3, она уже подключена на всех страницах).

## 8. Файлы, которые не нужно трогать (база данных и API)

- `js/core/api.js` — слой запросов к Google Apps Script. Не менять.
- `js/core/config.js` — здесь `API_URL` (адрес бэкенда) и время работы
  салона (`WORK_START`/`WORK_END`/`SLOT_INTERVAL`/`PREP_BUFFER`) — время
  работы менять можно, `API_URL` — нет.
- `js/core/global-cache.js`, `js/core/storage.js` — кэш и локальное
  хранилище данных записи. Не менять.
- Папка `barber_panel/` — панель администратора барбершопа (список
  заявок, синхронизация). Не связана с оформлением клиентской части и не
  затрагивалась при этой переделке.

## 9. Общая карта файлов

```
index.html            Шаг 1 — выбор мастера + галерея работ
Services.html          Шаг 3 — выбор услуг
Free-slots.html        Шаг 2 — выбор даты и времени
Contacts-form.html     Шаг 4 — контактные данные + отправка записи
Thank-you.html         Шаг 5 — экран успеха
reviews.html           Отзывы
map.html               Карта проезда

css/theme.css           ⭐ цвета/шрифты обеих тем — правьте для ребрендинга
css/styles.css          вёрстка и компоненты (использует переменные из theme.css)

js/core/site-config.js  ⭐ единая точка: тема + название/адрес/слоган
js/core/config.js       адрес API и время работы — НЕ ТРОГАТЬ API_URL
js/core/api.js          запросы к бэкенду — не трогать
js/core/global-cache.js кэш слотов — не трогать
js/core/storage.js      локальное хранилище шагов записи — не трогать
js/core/init.js         диспетчер запуска страниц — не трогать

js/data/masters.js      ⭐ список мастеров
js/data/services.js     ⭐ список услуг и цен
js/data/gallery.js      ⭐ фото галереи "до/после"

js/utils/scissors-loader.js  кнопка-«ножницы» (индикатор загрузки)
js/utils/time.js             форматирование времени — не трогать
js/utils/helpers.js          вспомогательные функции + withButtonLock

js/pages/*.js           логика каждой страницы (нормально трогать разметку/тексты)

img/                    фото мастеров
img/gallery/            фото до/после для галереи (сейчас — плейсхолдеры)
```

⭐ — файлы, которые чаще всего и нужно редактировать при переделке под
новый салон.
